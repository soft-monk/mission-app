**附：落点（仅供追溯，不是需求）**
`apps/web/src/screens/SelfCheckScreen.tsx`（左栏宽度 / 逐项节拍 / 卡片图标）、`apps/web/src/App.tsx`（逐项重检的回调）；

素材 `apps/web/public/check-*.png`。

**一处未点名但必须做的（如实记在这里）**：实测发现同一块里的**组网链路**会红（`mesh-down`），
原因是探针在注册时**按值捕获**能力快照，而开机自检跑在浏览器 WS 连上之前；之后客户端连上也不会让**报告**自己重算
（"重新检测"用的仍是旧快照 → 永远红）。故在 `selfcheck.run` / `selfcheck.recheck` 开头各加了一次
`refreshCapabilities()`。实测：点一次【重新自检】→ 通信链路检测转 **normal**（三条子项全绿）。
**残留**：刚进本屏那一眼，组网链路可能仍显示红（开机自检跑在浏览器连上之前）；点一次重新自检即全绿。
