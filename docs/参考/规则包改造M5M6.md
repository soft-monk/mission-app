# 规则包改造方案 M5 / M6（可直接执行的 JSON 补丁）

| 项 | 内容 |
|---|---|
| 目标 | ① **M5/G5**：`scoring` 的**打击方案**补 `协同方式 / 预计完成时间 / IP 点 / 评估航线`；② **M6/G6**：`resource-alloc` 补 `altRange`（飞行高度范围） |
| 依据 | `参考文档/业务层宿主层实施方案.md:72`（M5）、`:73`（M6）、`:356`（G5）、`:357`（G6）、`:144`…`:148`（Excel 步 5 / 8 / 9） |
| 改动面 | **只改 2 个 JSON 文件**：`scoring/policies/mapapp/planTemplates.json`、`resource-alloc/policies/mapapp/deviceTypes.json`（备选见 §3.4.2）。**不动任何 `src/`、`include/`、`scripts/`、`tests/`、契约文档** |

### 3.1 M5 字段设计（`planTemplates.json` → `items[]`，**只落 `side:"strike"` 的 6 条**）

| 键名（camelCase） | 中文标签 | 类型 | 取值域 | 说明 |

| `coordination` | 协同方式 | string（枚举） | **`"simultaneous"` \| `"sequential"`** | 同时 / 序贯；小写枚举与既有取值风格一致（`higher`/`lower`/`count`/`ratio`/`reject-if-not-adopted`） |
| `plannedFinish` | 预计完成时间 | object | `basis: "from-t0"` + `minutes: int>0`；或 `basis:"absolute"` + `at:"YYYY-MM-DDTHH:mm:ss+08:00"` | `basis` 判别式把"绝对时刻 vs 相对分钟"这个**待裁决口径**变成纯取值（PATCH 级）改动，而不是形状变更（详见 Q1） |
