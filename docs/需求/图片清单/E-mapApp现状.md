  - **底栏 footer**：高 `var(--statusbar-h)` = **40px**，`borderTop`，`zIndex: 30`；**清屏模式保留**。
  - **浮层**：`PhasePanel` 以 `position: absolute; inset: 0; pointerEvents: 'none'; zIndex: 7` 铺满中央地图；`AlertToasts` 固定 `top: 64px / right: 318px / 宽 300px`（注释写明「右侧栏宽 300px + 间距」）；`VideoPanel` 入口固定 `left: 92px / bottom: 52px`。

## 启动 / 自检（views/*.tsx）

### BootScreen.tsx（启动加载屏）

- 屏名：无独立标题，顶栏为 `智能任务管理系统`。
- 主区逐字：大号 LOGO；`智能任务管理系统`（30px，letterSpacing 6）；`系统启动中，请稍候…`；进度条 + `{progress}%`。
- 面板一：标题 `模块加载进度`，`grid-4` 四列，列名 = 5 个模块（来自 store 初值，逐字）：`地图引擎`、`通信链路`、`AI引擎`、`集群管理`、`数据服务`（各带百分比条与 `{percent}%`；后端 `/health` 到达后用 `modules[].metric` 校准）。
- 面板二：标题 `系统状态`，4 行（来自 store 初值，逐字）：`网络连接` = `在线`、`数据链路` = `稳定`、`GPS 定位` = `正常`、`系统安全` = `安全`（`/health` 到达后被 `systemOverview` 覆盖）。
- 底栏逐字：`系统启动中，正在初始化核心模块…`，加载完成后变为 `核心模块已就绪，正在进入系统状态确认…`。
- 顶栏元素：`智能任务管理系统`、`网络：已连接`、wifi 图标、battery 图标、秒级时钟、头像占位圆。
- 按钮：**无任何按钮**（全屏无 onClick 控件）。
- 行为：`useEffect` 调 `loadBoot()`，内部 20 步 × 60ms 模拟进度（各模块目标值 `[100,100,100,100,100]`），结束后自动 `runSelfCheck()` → 切到 `selfcheck` 视图。

### SelfCheckScreen.tsx（一键自检屏）

- 屏名：面板内标题 `系统状态自检`。
- 顶栏逐字：`智能任务管理系统`、`网络：已连接`、wifi 图标、battery 图标（**无时钟、无头像**）。
- 左栏卡片逐字：`系统状态自检`；`请确认系统状态，确保各模块正常运行`；LOGO；按钮 `一键自检`（运行中变 `自检中…`）；底部提示 `自检过程预计耗时 15~30 秒`。
- 中栏面板 标题 `自检结果`：
  - 空态逐字：`点击【一键自检】开始分项检测`。
  - 每项渲染 `it.name` + `it.sub` + 状态 `正常`/`异常`（`normal` → `正常` + check 图标；否则 `异常` + close 图标）。项内容由后端 `/health` 的 `selfCheck` 决定；后端不可达时兜底硬编码一条：`通信链路检测` / `后端不可达` / `abnormal`。
- 右栏面板 标题 `系统状态概览`：渲染 `bootOverview` 键值（同 BootScreen 的 4 项）。当 `done && !allNormal` 时追加提示逐字：`存在异常项，可重检后进入`。
- 按钮（3 个，**均真的能点**）：
  - `一键自检` → `onClick={() => void run()}` → `runSelfCheck()` → `GET /api/v1/health`；`disabled={running}`。
  - `重新检测` → 同上 `run()`；`disabled={running}`。
  - `进入任务 »` → `onClick={() => void enter()} `→ `await bootstrap()`（拉 `/scenarios`、`/map/config`、`/missions/current`）→ `setView('flow')`；`disabled={!done}`。
